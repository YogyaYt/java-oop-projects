### 🤖 SideKick

A Java practice project focused on implementing encapsulation using private fields, getters, setters, and input validation.

### 🤖 RobotInheritance

A Java project demonstrating how inheritance allows specialized robot classes to reuse common functionality from a parent Robot class.

**Concepts Learned**
- Inheritance
- Parent & Child Classes
- Method Inheritance
- Method Overriding
- Code Reusability

### 🤖 AbstractRobotLab

A Java project demonstrating abstraction by creating an abstract Robot class and implementing different robot types with their own behaviors.

**Concepts Learned**
- Abstract Classes
- Abstract Methods
- Inheritance
- Method Overriding
- Runtime Polymorphism
- Code Reusability
